# 🩺 Medi Void

> Offline-first medical information website — search medicines by symptoms in **Hinglish / Hindi / English**. No AI, no APIs, runs entirely in the browser.

![Medi Void — Social Preview / OG Image](assets/og-image.jpg)

[![Vercel Deploy](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://example.com/placeholder)

## ✨ Features

- **100% Offline-Capable** — Works from `file://` or any static host; no backend required
- **Tri-lingual Search** — Type in Hinglish (`sir dard`), Hindi transliteration, or English (`headache`)
- **Weighted Search + Fuzzy Match** — Levenshtein distance + keyword scoring (never returns empty)
- **Category Filtering** — Tap a category chip to filter + auto-scroll to results
- **Cross-page Deep Linking** — Pass `?cat=Painkillers` or `?q=fever` via URL params
- **Favorites** — Save meds locally via `localStorage` (`medivoid.favorites`)
- **A–Z Medicine Index** — Full alphabetical list
- **404 Page** — Custom, themed with search + quick links
- **Admin Panel** — Password-gated form to build, preview, live-test, then copy-paste new medicine entries
- **Theming** — Persistent light/dark mode toggle via `medivoid.theme`
- **Full SEO / Social Tags** — Meta, OpenGraph, Twitter Cards on all 6+ pages
- **Social Preview Image** — `assets/og-image.jpg` (1200×630 JPEG — SVG not supported by WhatsApp/FB)

### Workflow
1. **Form fill** — Autogenerated ID, category dropdown, type, icon, description,
   food timing, dosage, keywords, clickable `usedFor` symptom chips, side effects,
   warnings, storage etc.
2. **Live Preview** — Exact medicine card rendered on the right.
3. **Live Test** ⚡ Button injects the new medicine into a temporary `localStorage`
   bucket that `database.js` **auto-merges on every page-load**. The med instantly
   appears on Home / Categories / A–Z / Detail pages across the whole site.
4. **Copy-Paste** — Two output boxes with copy buttons:
   - **Step A →** `medicines.json` array entry
   - **Step B →** `medicines-data.js` inline fallback entry
5. **Backup / Export** — Full DB download (timestamped JSON) + Clear Live Tests.

## 🚀 Running Locally

### Option A — Double-click (simplest)
Just open `index.html` in a browser. Works because the site ships with
`medicines-data.js` (inline fallback) since `fetch(file://)` is blocked by browsers.

### Option B — Local HTTP server (recommended)
Any static server works:

```powershell
# Python 3
python -m http.server 8000

# OR Node (if installed)
npx serve .

# OR PHP
php -S localhost:8000
```

Then visit **http://localhost:8000**

## ☁️ Deploying to Vercel

### 1. Project structure is already Vercel-ready
A `vercel.json` is included that declares:
- **Static** build (no build command needed)
- `cleanUrls: true` — strips `.html` extension
- **Headers** — cache CSS/JS for 1h, images for 1 year, HTML revalidates
- **Security headers** on HTML (X-Frame-Options, X-Content-Type-Options, Permissions-Policy etc.)
- **`notFound` → `/404.html`** with HTTP 404
- Useful short **redirects** (`/home`, `/search`, `/az`, `/fav` etc.)

### 2. Deploy steps
```bash
# 1. Install vercel CLI once
npm i -g vercel

# 2. Run in project folder
vercel

# 3. Answer prompts (press Enter for defaults):
#    Set up and deploy? Y
#    Which scope?    (your Vercel account)
#    Link to existing? N
#    Project name:   medi-void
#    Directory:      ./  (current)
#    Framework:      Other
#    Build command:  (leave blank)
#    Output dir:     .  (current)
#    Dev command:    (leave blank)

# 4. Production deploy
vercel --prod
```

### 3. GitHub auto-deploy (optional)
Push this folder to a GitHub repo → visit **vercel.com/new** → import repo.
Every git push will auto-deploy.
